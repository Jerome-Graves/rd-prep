# R&D Prep

An interactive refresher for R&D instrumentation interviews: modern C++, DSP,
acoustics, control, electronics, embedded systems, and the numerical maths behind
instrument software.

**Use it here: https://jerome-graves.github.io/rd-prep/**

Fifteen lessons across six tracks, each with a quiz (instant feedback and
explanations) and an open interview question with a model answer, plus an
**800-question practice bank**: 100 each across C++, DSP, Acoustics, Control,
Electronics, CS and Maths, Robotics, and RTL and Verilog. Practice tests favour questions
you have not seen or previously missed, every answer is recorded, and the results
page ranks your topics weakest-first with links back to the lesson that covers each.
A question of the day rotates through the interview bank. All progress, scores and
the daily streak are stored locally in the browser.

Built as a single self-contained static page: no frameworks, no build step, no
tracking. `data.js` holds the lessons; add a lesson object and it appears in the
navigation automatically.
