# R&D Prep

An interactive refresher for R&D instrumentation interviews: modern C++, DSP,
acoustics, control, electronics, embedded systems, and the numerical maths behind
instrument software.

**Use it here: https://jerome-graves.github.io/rd-prep/**

Fifteen lessons across six tracks, each with a quiz (instant feedback and
explanations) and an open interview question with a model answer. A question of the
day rotates through the full bank. Progress, quiz scores and the daily streak are
stored locally in the browser.

Built as a single self-contained static page: no frameworks, no build step, no
tracking. `data.js` holds the lessons; add a lesson object and it appears in the
navigation automatically.
